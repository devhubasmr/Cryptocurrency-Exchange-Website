# Cryptocurrency Exchange Website

A cryptocurrency exchange website designed with HTML, CSS, and JavaScript.

## Getting Started

```bash
git clone https://github.com/devhubasmr/Cryptocurrency-Exchange-Website.git
cd Cryptocurrency-Exchange-Website
```

Then open `index.html` in your browser.

- CSS
- JavaScript
